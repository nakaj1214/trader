# 実証的プロンプト調整

詳細な手順: [INSTRUCTIONS.md](INSTRUCTIONS.md)

## 核心原則

「プロンプトの品質は書いた本人には分からない」

自己レビュー禁止。フレッシュなサブエージェントに実行させ、定性レポートを最重視する。

## リソース

- [INSTRUCTIONS.md](INSTRUCTIONS.md) — 7フェーズのワークフロー・評価メトリクス・収束判定
- [evaluations/evals.json](evaluations/evals.json) — テストケース

## 適用する場面

| 適用する | スキップしてよい |
|---------|--------------|
| スキル・コマンドを新規作成・大幅改訂 | 使い捨ての一回限りプロンプト |
| 動作が期待とずれている | 評価コストが効果を上回る |
| 頻繁に使うスキルの堅牢化 | |
