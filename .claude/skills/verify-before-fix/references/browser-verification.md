# ブラウザ検証リファレンス

フロントエンド問題の証拠収集に使用する確認依頼テンプレート。
verify-before-fix スキルの Phase 3 で、フロントエンドレイヤーの検証時に参照する。

---

## ユーザーへの確認依頼

フロントエンド問題は自動検証ツールを使わず、ユーザーに確認を依頼する。
以下のテンプレートを使って具体的な確認内容を伝える:

```markdown
## 確認依頼

現象の原因を特定するため、以下の確認をお願いします:

1. **確認手順**: [具体的な操作手順]
2. **確認ポイント**: [何を見ればよいか]
3. **期待値**: [正常ならこう見える]
4. **異常値**: [問題があればこう見える]

結果を教えていただければ、正確な修正を提案できます。
```

---

## 依頼できる証拠の種類

| 証拠 | 依頼方法 |
|------|----------|
| スクリーンショット | 「〇〇の状態のスクリーンショットを貼ってください」 |
| DOM 構造 | 「F12 → 対象要素を右クリック → Inspect → outerHTML をコピー」 |
| コンソールログ | 「F12 → Console タブを開いた状態で操作してください」 |
| 操作再現 | 「〇〇→〇〇→〇〇の順に操作したときの動作を教えてください」 |
