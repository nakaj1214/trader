# 決算発表予定日の取得可否（Free プラン）2026-10-07

目的: Monitor に「決算発表前の警告」を足せるかの調査。実装はしていない。読み取りの GET だけを実行した（J-Quants は7回、yfinance は4銘柄）。

## J-Quants V2（Free プラン、キーは手元の Free）
- `GET /v2/fins/earnings-date`（全上場銘柄、`scheduled_date`・`code`・`date` のいずれかを指定）と、`GET /v2/equities/earnings-calendar`（3・9月期のみ、パラメータなし）がある。
- **Free プランは、直近12週間に公表されたレコードが見えない。** `PubDate` の最大が 2026-07-15（調査日の12週前）だった。
- そのため、将来の予定日は、12週以上前に公表された暫定の日付しか取れない。`scheduled_date` ごとの件数:

| 予定日 | 件数 | 備考 |
|---|---:|---|
| 2026-05-14（過去、12週超） | 700 | 全件が見える |
| 2026-08-07（過去、12週未満） | 658 | 公表が12週前までのものだけ |
| 2026-09-30（過去、12週未満） | 0 | |
| 2026-10-30（将来） | 19 | 通常の件数は数百 |
| 2026-11-10（将来） | 22 | 同上 |

- `earnings-calendar`（3・9月期のみ）は、全体で1件（2026-10-05、過去の日付）しか返さなかった。
- **結論: Free プランでは、決算前の警告に使える予定日はほとんど取れない（将来の件数は通常の5%未満）。** 有料プランなら取れる可能性が高いが、プラン別の可否は公式ドキュメントに記載がなく、実際に試して確認していない。

## yfinance（`Ticker.calendar`）
- 大型株（7203.T、6758.T、9984.T）は `Earnings Date` が入る（確定か推定かは区別できない）。小型株（2753.T）は空だった。
- 本プロジェクトの対象は小型・中型の急騰候補なので、取得率は低いと見込まれる。保有銘柄は少数なので、取得率を実測してから判断する価値はある。

## 判断の材料
1. Free のままでは、決算前の警告は信頼できない。
2. 保有銘柄だけに yfinance を使う案は、取得率を実測してから、「あれば警告する（なくても沈黙する）」の補助として実装できる。確定日ではない可能性を、メッセージに明記する必要がある。
3. 有料プランに切り替える場合は、B1 の「財務ラグの比較」（有料に切り替える価値）と合わせて判断する。
